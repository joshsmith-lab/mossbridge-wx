# Shared project guidance

- The production app is https://joshsmith-lab.github.io/mossbridge-wx/ and is shared with family.
- Work on feature branches and use pull requests. Do not push directly to `main`, force-push, rename the repository, or change the GitHub Pages URL.
- Keep weather and marine guidance honest: unavailable data must be labeled unavailable, never replaced with invented values.
- Preserve the existing UI and UX unless Josh explicitly asks for design changes.
- Run `node --test test.mjs` before requesting review.
